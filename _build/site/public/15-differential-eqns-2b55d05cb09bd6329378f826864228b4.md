## <span class = "h2-num">15.1 </span><span class = "h2-text"> Introduction </span>
When we were in elementary school, we were taught how to solve linear equations like
\begin{equation*}
-2x+17 = 8x-13.
\end{equation*}
The algorithm started with us moving all of the unknows to the one side, all of the knows to the other side and then explicitly solving the equation for $x$.
